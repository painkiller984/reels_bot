# Эксплуатация

## Рабочий облачный режим

- OpenRouter создаёт сценарий и получает изображение продукта как визуальный контекст.
- HeyGen создаёт аватара автоматически, по описанию или из фотографии, выполняет озвучку и предоставляет фоновую музыку.
- FFmpeg внутри контейнера добавляет товар, плавное появление, субтитры и сводит музыку с речью.
- PostgreSQL хранит задания и восстанавливает прерванное производство после рестарта.
- Telegram webhook используется автоматически при наличии `RENDER_EXTERNAL_URL`; локальный запуск использует long polling.
- Готовый MP4 автоматически отправляется пользователю и остаётся доступен через `/preview`, пока живёт экземпляр контейнера.

## Секреты

В Git не добавляются `.env`, изображения с ключами, OAuth-токены и артефакты. В Render задаются только три обязательных секрета:

- `TELEGRAM_BOT_TOKEN`;
- `OPENROUTER_API_KEY`;
- `HEYGEN_API_KEY`.

## Ограничения текущего этапа

- YouTube подключается после проверки производства ролика; Instagram и TikTok пока отключены.
- In-process очередь восстанавливает производство из хранилища после рестарта, но не распределяется между несколькими процессами.
- Файлы рендера на бесплатном Render временные, поэтому бот отправляет результат сразу после завершения. Для постоянного архива потребуется объектное хранилище.
- Для экономии баланса автоматические тесты не запускают платную генерацию HeyGen.

## Проверка готовности

```powershell
npm run typecheck
npm test
npm run build
```

После развёртывания отправьте боту `/health`, затем создайте один короткий 15-секундный тест через `/create`.
